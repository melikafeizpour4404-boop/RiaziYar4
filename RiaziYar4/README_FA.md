# ریاضی‌یار ۴ — نسخه وب فارسی

## چه چیزهایی در این بسته وجود دارد؟
- رابط فارسی و راست‌چین با تم سفید و صورتی
- نقش‌های طراح اصلی، مدیر مدرسه، معلم و دانش‌آموز
- ثبت مدرسه توسط طراح اصلی و ساخت حساب مدیر
- ساخت کلاس و ایجاد حساب معلم/دانش‌آموز
- بارگذاری فایل از داخل خود سایت در مخزن خصوصی آنلاین
- نمایش محتوای آموزشی و ثبت/نمایش نمرات با محدودیت نقش در رابط برنامه
- امضای ثابت پایین صفحات: «طراح و سازنده سامانه: ملیکا فیض‌پور»

## مهم: قبل از انتشار عمومی
این بسته یک نسخه اولیه قابل اجرا برای راه‌اندازی و آزمایش است، نه سامانه تأییدشده برای نگهداری اطلاعات واقعی دانش‌آموزان. کد فعلی از کلید سرویس Supabase در سمت سرور استفاده می‌کند و کنترل نقش‌ها در لایه برنامه انجام می‌شود؛ این روش به‌تنهایی جایگزین امنیت سطح پایگاه داده (RLS)، آزمون نفوذ، ثبت رویدادها و بازبینی تخصصی حریم خصوصی نیست. تا تکمیل این موارد، از اطلاعات واقعی، نمرات واقعی یا فایل‌های حساس دانش‌آموزان استفاده نکنید.

## راه‌اندازی فنی
1. یک پروژه Supabase بسازید.
2. در بخش SQL Editor، محتوای `schema.sql` را کامل اجرا کنید.
3. در Storage مطمئن شوید bucket با نام `learning-files` خصوصی (Private) است.
4. از Project Settings بخش API، آدرس پروژه و Service Role Key را بردارید. این کلید محرمانه است؛ آن را در GitHub یا داخل کد قرار ندهید.
5. فایل‌ها را در یک مخزن خصوصی GitHub قرار دهید.
6. در Streamlit Community Cloud برنامه را از `app.py` منتشر کنید.
7. در بخش App settings → Secrets این موارد را با مقادیر پروژه خود ثبت کنید:

```toml
SUPABASE_URL = "https://YOUR-PROJECT.supabase.co"
SUPABASE_SERVICE_ROLE_KEY = "YOUR_SECRET_SERVICE_ROLE_KEY"
```

8. برنامه را Restart کنید.

## ساخت حساب طراح اصلی
برای ایمنی، حساب طراح اصلی باید مستقیماً توسط مدیر فنی پایگاه داده ساخته شود؛ فرم عمومی برای ساخت نقش طراح وجود ندارد. پس از اجرای schema، در SQL Editor این دستور را با مقدارهای واقعی خود اجرا کنید. هش گذرواژه را ابتدا در محیط پایتون امن بسازید:

```python
from passlib.hash import pbkdf2_sha256
print(pbkdf2_sha256.hash("یک-گذرواژه-قوی-و-منحصربه‌فرد"))
```

سپس مقدار خروجی را در دستور زیر جایگزین کنید:

```sql
insert into public.users
(id, username, full_name, password_hash, role, active)
values
(gen_random_uuid(), 'melika_admin', 'ملیکا فیض‌پور',
'PASTE_HASH_HERE', 'designer', true);
```

## اجرای آزمایشی روی کامپیوتر
در پوشه پروژه:
```bash
python -m venv .venv
```
فعال‌سازی ویندوز:
```bash
.venv\Scripts\activate
```
نصب:
```bash
pip install -r requirements.txt
```
اجرا:
```bash
streamlit run app.py
```

## نکات مهم درباره نسخه فعلی
- فایل‌ها از طریق دکمه آپلود داخل سایت انتخاب می‌شوند و در bucket خصوصی Supabase ذخیره می‌شوند.
- حجم فایل در این تنظیم اولیه حداکثر 100 مگابایت است؛ محدودیت‌های پلن Supabase را نیز بررسی کنید.
- این نسخه برای آزمون عملکرد و تکمیل مرحله‌ای ساخته شده است. قابلیت انتساب معلم به چند مدرسه، آزمون‌ساز کامل، بازیابی گذرواژه، تغییر گذرواژه از پنل، گزارش‌گیری پیشرفته و سیاست‌های کامل RLS هنوز پیاده‌سازی نشده‌اند.
- دسترسی طراح به نمرات در رابط کاربری بسته شده است، اما برای تضمین واقعی این محدودیت باید معماری احراز هویت و RLS قبل از ورود اطلاعات واقعی بازطراحی و ممیزی شود.
